# Flock This (five8nine Studios edition)

A top-down night-city errand driving game. Run each level's chain of stops (cheese to the Pizza Shop, a lost dog to the vet, a cake to the party) and keep out of the red Flock camera cones, sweeping cameras and patrol cars. 14 levels, 3 stars each (finish, beat par, never spotted).

Play: https://ploug76.github.io/flock-this-589/

- Phone first: touch & drag stick (or on-screen buttons); arrows/WASD on desktop. Works offline (PWA).
- index.html is built from /workspace/flock-this-src (build.py) with the standard Share/Install dock, sample cap and shared leaderboard.
- `?qa=unlock` unlocks every level for testing (nothing saved or posted).
